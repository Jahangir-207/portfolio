## ✨ About This Project

This repository hosts my **personal developer portfolio** — a single-page, fully responsive website built to showcase who I am, what I've learned, and what I've built. It features a dynamic hero section with a typing animation, a tilt-effect image gallery, scroll-reveal animations, an interactive particles background, and a working contact form.

> *"I'm a B.Tech CSE student passionate about Web Development & Data Science, constantly building dynamic full‑stack applications with modern technologies."*

---

## 🚀 Features

| | |
|---|---|
| 🎯 **Animated Hero Section** | Particle.js background + Typed.js rolling text |
| 🖱️ **3D Tilt Effects** | Vanilla-Tilt.js on profile & project images |
| 🌀 **Scroll Reveal Animations** | Smooth section entrances via ScrollReveal.js |
| 📱 **Fully Responsive** | Mobile-first layout, works on every screen size |
| 🧩 **Modular Sections** | Home · About · Skills · Education · Work · Certifications · Contact |
| 📬 **Working Contact Form** | Name, email, phone & message with live status feedback |
| 🏆 **Certifications Showcase** | Auto-fallback image handling if a cert image is missing |
| 🧭 **Custom 404 Page** | Branded "Page Not Found" experience |
| 🌙 **Clean UI/UX** | Font Awesome icons + custom CSS theme |

## ⚡ Getting Started

Run the portfolio locally in under a minute:

```bash
# 1. Clone the repository
git clone https://github.com/Jahangir-207/portfolio.git

# 2. Move into the project folder
cd portfolio

# 3. Open it in your browser
#    (or use a live server for hot reload)
open index.html          # macOS
start index.html         # Windows
```

> 💡 **Tip:** Use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension for auto-refresh while editing.
